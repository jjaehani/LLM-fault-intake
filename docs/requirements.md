# 요구사항 정의서

| 항목 | 내용 |
|---|---|
| 시스템명 | LLM 기반 고장 접수 챗봇 |
| 작성 | 2026년 11월 (초안) |
| 비고 | 카카오톡 챗봇에서 LLM으로 산업장비 고장 증상을 접수하는 개인 프로젝트다. 실제 업체 자료는 쓰지 않고, 가상의 서비스를 가정해 직접 작성했다. |

## 목차

### 기능

## 설계 원칙

- LLM이 정리한 내용은 초안으로 둔다. 접수자가 잘못 입력하거나 LLM이 잘못 읽으면 접수 내용 자체가 틀어지므로, 확정은 담당자가 한다.
- 어디까지 자동화할지는 틀렸을 때 누가 고치는지를 먼저 보고 정한다.
- 모르는 정보는 추측해서 채우지 않고 되묻거나 비워 둔다.
