# 화면 설계

카카오톡 챗봇 화면은 말풍선과 버튼으로 구성된다. 화면마다 구성과 대화 예시를 적었다.
대화 예시의 장비와 증상은 설명을 위해 지어낸 것이다. 요구사항 ID는 [요구사항 정의서](requirements.md)와 같다.

## 화면 목록

| 화면 ID | 화면명 | 관련 요구사항 |
|---|---|---|
| S-01 | 시작 | FIT-001, FIT-009 |
| S-02 | 증상 입력과 되묻기 | FIT-001, FIT-002, FIT-003, FIT-005 |
| S-03 | 접수 내용 확인 | FIT-004 |
| S-04 | 접수 완료 | FIT-006 |
| S-05 | 범위 밖 질문 | FIT-008 |
| S-06 | 오류 안내 | FIT-NF4 |
| S-07 | 진행 상태 조회 | FIT-009 |
| S-08 | 담당자 확인 (초안) | FIT-006, FIT-007 |

## S-01 시작

채팅방에 들어오면 처음 보이는 화면이다.

```
[챗봇] 안녕하세요. 장비 고장 접수를 도와드려요.
       어떤 일로 오셨나요?

       ( 고장 접수하기 )  ( 접수 상태 보기 )
```

- `고장 접수하기`를 누르면 S-02로 간다.
- `접수 상태 보기`를 누르면 S-07로 간다.
- 버튼을 누르지 않고 바로 증상을 입력해도 S-02로 처리한다.

## S-02 증상 입력과 되묻기

접수자가 자유롭게 말하면 LLM이 항목을 뽑고, 빠진 항목을 한 가지씩 묻는다.

```
[접수자] 프레스가 아까부터 소리가 이상하고 멈췄다 섰다 해요

[챗봇] 언제부터 그랬나요?
       ( 오늘 )  ( 어제 )  ( 며칠 전부터 )

[접수자] 오늘

[챗봇] 지금 작업이 멈춘 상태인가요?
       ( 완전히 멈춤 )  ( 느리지만 작동 )  ( 정상 작동 )

[접수자] 완전히 멈춤

[챗봇] 고장 부위 사진이 있으면 보내 주세요. 없으면 건너뛰어도 돼요.
       ( 건너뛰기 )
```

- 장비 종류, 증상, 발생 시점, 긴급도 중 빈 항목만 묻는다.
- 긴급도는 접수자에게 직접 고르게 하고, LLM이 정하지 않는다.
- 사진은 선택이다. 보낸 사진은 이 접수에 연결해 저장한다.

## S-03 접수 내용 확인

정리된 내용을 카드로 보여 주고 확인받는다.

```
[챗봇] 이렇게 접수할게요. 맞나요?

       ┌─────────────────────────┐
       │ 장비      프레스          │
       │ 증상      이상한 소리, 멈춤 반복 │
       │ 발생 시점  오늘            │
       │ 긴급도    높음 (완전히 멈춤)  │
       │ 사진      1장             │
       └─────────────────────────┘

       ( 맞아요 )  ( 고칠게요 )
```

- `맞아요`를 누르면 S-04로 간다.
- `고칠게요`를 누르면 고칠 항목을 고르게 하고, 그 항목만 다시 입력받는다.

## S-04 접수 완료

```
[챗봇] 접수됐어요. 접수 번호는 F-0001이에요.
       담당자가 내용을 확인한 뒤 연락드릴게요.

       ( 접수 상태 보기 )  ( 처음으로 )
```

- 수리 가능 여부나 비용은 챗봇이 말하지 않는다. 담당자가 확인한 뒤 안내한다.

## S-05 범위 밖 질문

```
[접수자] 점심 메뉴 추천해 줘

[챗봇] 저는 장비 고장 접수만 도와드릴 수 있어요.

       ( 고장 접수하기 )  ( 접수 상태 보기 )
```

## S-06 오류 안내

LLM 호출이 실패했을 때 보이는 화면이다.

```
[챗봇] 지금 접수 정리가 잠시 안 되고 있어요.
       입력하신 내용은 저장해 두었어요.
       급하시면 담당자에게 직접 접수해 주세요.

       ( 다시 시도 )  ( 담당자 연락처 보기 )
```

## S-07 진행 상태 조회

```
[챗봇] 최근 접수 내역이에요.

       F-0001  프레스  담당자 확인 중
```

- 상태는 접수됨, 담당자 확인 중, 확정 세 가지다.

## S-08 담당자 확인 (초안)

담당자 화면을 웹으로 만들지 챗봇 안에서 처리할지는 아직 정하지 않았다. 아래는 웹으로 만들 경우의 초안이다.

**접수 목록**

| 접수 번호 | 장비 | 긴급도 | 상태 | 접수 시각 |
|---|---|---|---|---|
| F-0001 | 프레스 | 높음 | 담당자 확인 중 | 11:20 |

**접수 상세**

- 접수 항목 전체를 고칠 수 있다.
- 접수자가 처음 보낸 원문과 사진을 함께 보여 준다. LLM이 잘못 정리한 곳을 원문과 비교해 고치기 위해서다.
- `확정` 버튼을 눌러야 접수가 완료된다.
